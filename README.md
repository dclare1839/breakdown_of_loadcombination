# breakdown_of_loadcombination
To calculate the breakdown of load combination and make a report based on the civil nx model.

🚀 Project Overview
This plugin is developed to extend the analytical capabilities of MIDAS Civil NX. While the built-in Load Combination feature is often limited to ULS Envelope results, this tool leverages the Civil NX API and Python to provide a more comprehensive and automated workflow for structural engineers.

Key Features
Eurocode Compliance: Automatically generates a full suite of ULS (Ultimate Limit State) and SLS (Serviceability Limit State) load combinations according to EN 1990.

API Integration: Seamlessly connects Python scripts with the MIDAS Civil NX environment for real-time data exchange.

Detailed Visualization: Provides a "Breakdown" view of member forces and displacements for every individual combination, moving beyond simple envelope summaries.

Automated Reporting: Generates professional-grade final reports, significantly reducing manual post-processing time.
